# 月夜の小石

四つのプロフィールを切り替え、凡庸な幸せを投稿・返信できるローカルファーストの小さなSNSです。

- 投稿・プロフィール・読み込んだフォントはブラウザ内だけに保存されます。
- サーバーへの投稿送信やクラウド同期はありません。
- 小石のバックアップはアプリ内の「書き出す」から作成できます。

## 気持ちの穴

庭の「気持ちを置きにいく」から、名前を選ばず言葉を投げられます。言葉は普段は隠れ、任意に読んでまた隠せます。

- 穴の言葉・書きかけは、小石とは別のブラウザ内保存です。送信・同期はありません。
- 「穴を埋める」は確認後、穴の言葉と書きかけだけを消します。小石・プロフィール・共通フォントは残ります。
- 手持ちのフォントは庭と共有し、端末内のIndexedDBに保存します。フォントファイルは配布しません。
- 穴は小石の書き出しに含まれず、バックアップ機能はありません。サイトデータ削除で失われます。
- ブラウザ内保存は暗号化・アクセス認証ではありません。同じ端末・ブラウザを使う人には見られます。リセットはOS等のバックアップまで消しません。
- 全児童フォントの有料版ファイルは配布物に含まれません。利用者が権利を持つフォントを端末から読み込む設計です。
